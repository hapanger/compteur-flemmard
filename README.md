# Compteur flemmard

Mini compteur de points pour Barbu, optimise pour iPhone.

## Utilisation

Ouvre l'URL GitHub Pages dans Safari sur iPhone, puis ajoute-la a l'ecran d'accueil.

Les donnees sont sauvegardees dans le navigateur utilise.

## GitHub Pages

Dans GitHub : `Settings` -> `Pages` -> `Deploy from a branch` -> branche `main` -> dossier `/root`.
